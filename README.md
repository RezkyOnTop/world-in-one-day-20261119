A one-page front page of Thursday 19 November 2026's world news: eight stories
from five continents, drawn as a 1024x1024 PNG by `build.py` and copied to the
grader's `/output/entry.png` by `main.py`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
